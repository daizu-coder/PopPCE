PopPCE (Windows CE port of NitroGrafx) - Third-party licenses
==============================================================

PopPCE is an unofficial, non-commercial port of NitroGrafx. It is not an
official NitroGrafx release, and the original author is not involved.
See CE/LICENSING.md for how PopPCE itself is licensed; PopPCE's own code
(listed there) is MIT, see CE/LICENSE.

This file lists the third-party components in the PopPCE sources and in
AppMain.exe, with their copyright notices and license texts.

SuperGrafx game list (CE/core/pce_core_ce.c: sgxCrcs)
-----------------------------------------------------
To recognise SuperGrafx HuCards that are dumped as .pce, PopPCE checks
the CRC32 of the image against six values. These CRC values and game
titles are factual data about the original game images; the list was
taken as a reference from the SuperGrafx game list in
beetle-supergrafx-libretro:

  https://github.com/libretro/beetle-supergrafx-libretro
  mednafen/pce_fast/pce.cpp (sgx_table), commit 3c6fcd3

No Mednafen code is used in PopPCE. Thanks to the Mednafen project and
the libretro team, who maintain the libretro port, for compiling this
list.

Fonts
-----
The PopPCE binary (AppMain.exe) embeds bitmap glyph data for its
Japanese/English menu text. The default build (make, CE_FONT=galmuri14)
uses glyphs converted from the Galmuri14 font; the few characters
Galmuri14 does not have (Greek, Cyrillic and some math symbols) are
filled in from the Shinonome 16dot font. Both are described below.
